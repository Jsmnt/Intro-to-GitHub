Intro to GitHub

Git is a free, open-source distributed version control system created by Linus Torvalds in 2005 for developing the Linux kernel. It runs on your own computer and records every change made to a project's files, so you can see who changed what, when, and why, and go back to any earlier version.

GitHub is a cloud-based hosting service for Git repositories, owned by Microsoft. It stores Git repositories online and provides collaboration features such as pull requests, code review, issue tracking, GitHub Actions, and GitHub Pages.

Git vs GitHub

Git GitHub
A tool installed on your computer A website and online service
Tracks changes and manages versions Hosts Git repositories for sharing and collaboration
Works offline through the command line or GUI Uses the internet through a browser, desktop app, or CLI
Open-source and maintained by the Git community Commercial product owned by Microsoft
Commit, branch, and merge Pull requests, issues, code review, Actions, and Pages

In short: Git is the version control tool, while GitHub is a place to store and share Git projects online.

1.2 Purpose of Version Control in Software Development

Version control is a system that records changes to files over time so specific versions can be recalled later.

  • Keeps a complete history of every change.
  • Supports teamwork and collaboration.
  • Tracks who made each change, when, and why.
  • Allows safe experimentation using branches.
  • Serves as a backup of the project.
  • Supports releases and automation.

1.3 Basic Git Concepts

Concept Description
Repository (Repo) A folder that contains a project's files and its complete history of changes.
Commit A saved snapshot of the project at a specific point in time.
Branch An independent line of development used for features or fixes.
Pull Request (PR) A GitHub feature used to propose changes from one branch to another.
Merging Combining changes from one branch into another.
Clone / Push / Pull Clone copies a remote repository, Push uploads local commits, and Pull downloads and merges new changes.
